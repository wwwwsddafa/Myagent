# LangChain 开发指南

            ## 什么是 LangChain
            LangChain 是一个用于开发大语言模型应用的开源框架。
            它提供了模块化的组件，让开发者可以轻松构建 LLM 应用。

            ## 核心组件
            - Model I/O: LLM 和 Chat Model 的接口
            - Retrieval: RAG 检索增强生成的组件
            - Chains: 链式调用
            - Agents: 自主决策的 Agent
            - Memory: 对话记忆

            ## LangGraph
            LangGraph 是 LangChain 的扩展，专门用于构建有状态的、多角色的应用。
            它基于图结构，支持循环、条件分支等复杂工作流。
